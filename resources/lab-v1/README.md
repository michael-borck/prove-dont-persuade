# lab-v1

Synthetic teaching fixtures authored for Prove, Don't Persuade, 2026-09-14.
Not original Tessera exports, real customer records, or measurements of a model.
Use and attribution follow the book's declared CC BY licence.
Appendix G prints all inputs and explains the scoring conventions and limitations.
Keep these versioned files unchanged; make a new lab version for changed examples.

`SHA256SUMS` records the three input files. The manuscript checks verify these
digests, the printed copies, and the answer arithmetic. Run from the book root:

```sh
python scripts/check_manuscript.py
```
